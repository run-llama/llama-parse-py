# Security Policy

## Reporting Security Issues

If you believe you have found a security vulnerability in this SDK or in the LlamaCloud APIs it
calls, please report it privately to support@runllama.ai. Do not open a public GitHub issue for
security reports.

## Responsible Disclosure

We appreciate the efforts of security researchers and individuals who help us keep LlamaCloud
secure. Please allow us a reasonable amount of time to investigate and address an issue before
making any information public.

---

Thank you for helping us keep LlamaCloud and the systems it interacts with secure.
